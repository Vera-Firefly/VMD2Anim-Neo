VMD2Anim Neo 1.0.0 is the first stable Windows desktop release for converting MMD VMD motions to Unity `.anim` files.

### Features

- Acrylic interface with batch conversion, drag and drop, and a conversion log.
- Humanoid and FK output with source PMX, target FBX, HPS rig and skeleton descriptor support.
- Independent animation output mode, Facial VMD and source IK settings for each motion.
- English and Simplified Chinese, selected from the system display language by default, with instant manual switching.
- Settings and About pages, with persistent preferences and Apache-2.0 licensing.
- Successful motions leave the queue automatically; failed and cancelled motions remain for retry. Existing output files are preserved.
- Corrected dropdown selection and language refresh, consistent control styling, sidebar selection, and protection against accidental wheel changes in closed dropdowns.

### Install

Download `VMD2Anim-Neo-win-x64.zip`, extract the entire archive and run `VMD2Anim-Neo.exe`. Keep the `Core` folder beside the app. The package includes the .NET runtime; no separate .NET installation is needed. The `.sha256` asset contains the archive checksum.

For instructions, see the included `README.md` or `README.zh-CN.md`.

VMD2Anim Neo 1.0.0 是首个 Windows 桌面正式版，可将 MMD VMD 动作转换为 Unity `.anim` 文件。

### 功能

- 亚克力界面，支持批量转换、拖放和运行日志。
- 支持 Humanoid 与 FK 输出，以及源 PMX、目标 FBX、HPS Rig 和骨架 Descriptor。
- 每个动作均可独立设置动画输出模式、Facial 表情文件与源 IK。
- 支持英语和简体中文，默认跟随系统显示语言，也可手动即时切换。
- 提供设置和关于页面，自动保存偏好，采用 Apache-2.0 协议。
- 成功后自动移出队列，失败和取消的动作保留以便重试；保留已有输出文件。
- 修复下拉框选中状态、语言刷新和导航高亮，统一控件样式，避免收起的下拉框被滚轮误改。

### 安装

下载 `VMD2Anim-Neo-win-x64.zip`，完整解压后运行 `VMD2Anim-Neo.exe`，保留程序旁的 `Core` 文件夹。发布包自带 .NET 运行时，无需另行安装。`.sha256` 文件用于校验压缩包。

使用方法见压缩包内的 `README.zh-CN.md`。
