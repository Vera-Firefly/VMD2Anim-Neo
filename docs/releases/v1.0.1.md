VMD2Anim Neo 1.0.1 simplifies the conversion workspace and settings interface.

## Changes

- Removed redundant descriptions and shortened empty-queue, ready and completion messages.
- Adjusted spacing after removing descriptions; empty status messages no longer reserve space.
- Changed Facial, output and source IK summaries, and the current conversion filename, to use colons.
- Displayed JSON file formats in parentheses in the target skeleton selector.
- Updated English text to match the revised Chinese interface.

## Download

Download `VMD2Anim-Neo-win-x64.zip`, extract the entire archive, and run `VMD2Anim-Neo.exe`. Keep the `Core` folder beside the app. The Windows x64 package includes the .NET runtime; the accompanying `.sha256` file can be used to verify the download.
